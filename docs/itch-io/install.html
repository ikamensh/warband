Windows 10/11 · 64-bit
Requires OpenGL 3.3-compatible graphics drivers. Use the Windows installer for a Start menu shortcut, or extract the portable ZIP and run Warband.exe.

macOS 14+ · Apple Silicon (M1 or later)
Extract the Mac app ZIP, drag Warband.app into Applications, then open it. Intel Macs are not supported by this build.

These Early Access builds are unsigned (the Mac app is ad-hoc signed, without Apple notarization), so your operating system may ask you to confirm the first launch. See the official installation guide for details.

Controls: keyboard and mouse or trackpad. Drag to select; right-click to move, gather, or attack. On Mac, two-finger click or Control-click is right-click. Press A then click to attack-move; F1 opens help, F2 the Codex.

Campaigns and skirmishes play offline. Internet is required for online multiplayer; everyone in the room should use the same version.
